# 在 Kite 中搜索本机文件

点击搜索框右侧的“文件”，再点击列表中的“启用文件搜索”。确认页说明采集范围，点击“启用文件搜索”继续；首次使用时，Windows 弹出管理员授权，以安装按需读取组件。已有组件和索引会自动复用。

建库按阶段显示读取磁盘、构建索引、同步最新变化。期间仍可使用应用搜索；完成后输入文件名关键词即可搜索。索引构建与追平可能临时多用内存，就绪前会释放启动缓存。

## 搜索与类型筛选

- 输入至少两个字符，按文件名匹配；多个空格分隔的关键词需要同时出现。
- 文件模式中的“全部／图片／文档／视频／音频／压缩包／文件夹”只筛选文件结果。
- 文件结果可直接打开，沿用 Kite 的键盘选择与右键操作。
- 完整本地路径仍可使用 Kite 原有的路径直达。

## 重建索引与排除文件夹

打开“设置 → 文件搜索”。插件页中的“文件搜索”保留开关和状态，点击“管理”也可进入此页。

日志保留范围不足、日志身份变化，或索引明确失效时，Kite 自动在后台恢复，无需手动点击重建。设置页和文件搜索结果显示“正在恢复文件索引”；期间应用搜索继续可用，可以关闭文件搜索取消恢复。完整的新索引就绪后才替换旧基库。

**重建索引**保留为主动维护入口，重新读取本机 NTFS 名字元数据，再构建和追平。每次启动或重试最多自动恢复一次；恢复仍失败时显示原因和“重试恢复”，避免反复全盘重建。权限不足、磁盘写入失败、连接中断等普通故障显示具体原因，不触发自动重建。

在**排除文件夹**中添加目录，目录自身及全部子目录立即从结果中隐藏，移除后恢复，无需重建。每条硬链接路径独立判断，排除目录外的另一个名字仍可搜索。排除控制结果可见性，底层仍采集完整名字元数据，以便正确处理目录改名和范围间移动。

## 权限与后台运行

读取组件仅提供本机 NTFS 文件名、路径、身份和现有 USN 变更，不读取文件内容，不安装驱动，不修改 USN。文件名和路径也可能包含隐私信息，组件通信和本地元数据按用户隔离。

- 插件默认关闭，未启用时不安装组件、不读取磁盘索引。
- 首次安装，以及需要更新或移除组件时申请管理员权限；拒绝后可重试，应用搜索继续可用。
- Kite、查询、打开文件和其他插件保持普通权限。
- 开启后只在 Kite 运行期间跟踪变化；关闭插件或退出 Kite 会停止这一会话，无其他会话时服务退出。
- 关闭后保留基库和已经完整提交的变化状态；下次从最近完整提交的全卷游标继续补读。游标与文件变化在同一事务中保存，原始建库游标保留作身份校验依据。若需要读取的位置已被 Windows 日志覆盖，或日志身份发生变化，自动重新采集、构建并追平后继续同步。
- 大批文件变化写入本地磁盘表，按文件身份更新或删除，查询直接合并基库与已提交的磁盘变化。65,536 个变化对象／64 MiB 变化层及单会话 512 MiB 日志不再作为累计容量上限；内存由分页读取、有限帧和数据库缓存控制。
- 同步按完整一轮提交。进程中断后保留上一轮已提交状态；重启从对应游标重读未提交部分。确认的日志连续性丢失进入自动恢复；磁盘满、写入失败等问题保留最后完整提交状态并显示原因，处理原因后重试。
- 会话日志分段写入，查询端确认数据已持久消费后回收旧段。退出后清理本轮采集暂存与会话日志，保留恢复所需的受保护起始身份；完整重建成功后清理上一份搜索基库及其变化数据库。
- 读取组件协议为 4，保留可机器识别的日志失效原因。升级后若读取组件版本较旧，会提示授权更新；安装器会更新已经安装的组件。已有基库可继续复用；持久恢复和大批变化的实机验证范围见[验证摘要](FILE-SEARCH-VALIDATION.md)。

## 数据位置

用户设置、排除目录与最终搜索索引保存在 `%APPDATA%\com.kite.launcher`。读取组件安装在受保护的程序目录，采集暂存放在 `%ProgramData%\Kite\FileIndex` 的用户隔离会话中。数据仅在本机使用，不上传。
