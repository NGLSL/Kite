# 在 Kite 中搜索本机文件

点击搜索框右侧的“文件”，再点击列表中的“启用文件搜索”。确认页说明采集范围，点击“启用文件搜索”继续；首次使用时，Windows 弹出管理员授权，以安装按需读取组件。已有组件和索引会自动复用。

建库按阶段显示读取磁盘、构建索引、同步最新变化。期间仍可使用应用搜索；完成后输入文件名关键词即可搜索。索引构建与追平可能临时多用内存，就绪前会释放启动缓存。

## 搜索与类型筛选

- 输入至少两个字符，按文件名匹配；多个空格分隔的关键词需要同时出现。
- 文件模式中的“全部／图片／文档／视频／音频／压缩包／文件夹”只筛选文件结果。
- 文件结果可直接打开，沿用 Kite 的键盘选择与右键操作。
- 当前搜索不解析 Everything 的查询表达式；完整本地路径仍可使用 Kite 原有的路径直达。

## 重建索引与排除文件夹

打开“设置 → 文件搜索”。插件页中的“文件搜索”保留开关和状态，点击“管理”也可进入此页。

**重建索引**重新读取本机 NTFS 名字元数据，再构建和追平。完整的新索引就绪后才替换旧基库；失败时显示原因与重试入口。

在**排除文件夹**中添加目录，目录自身及全部子目录立即从结果中隐藏，移除后恢复，无需重建。每条硬链接路径独立判断，排除目录外的另一个名字仍可搜索。排除控制结果可见性，底层仍采集完整名字元数据，以便正确处理目录改名和范围间移动。

## 权限与后台运行

读取组件仅提供本机 NTFS 文件名、路径、身份和现有 USN 变更，不读取文件内容，不安装驱动，不修改 USN。文件名和路径也可能包含隐私信息，组件通信和本地元数据按用户隔离。

- 插件默认关闭，未启用时不安装组件、不读取磁盘索引。
- 首次安装，以及需要更新或移除组件时申请管理员权限；拒绝后可重试，应用搜索继续可用。
- Kite、查询、打开文件和其他插件保持普通权限。
- 开启后只在 Kite 运行期间跟踪变化；关闭插件或退出 Kite 会停止这一会话，无其他会话时服务退出。
- 关闭后保留基库，下次从基库原始游标补读退出期间的变化。若 Windows 日志已覆盖该位置，或卷／日志身份变化，会提示重建。
- 变化层或单次会话日志达到上限时也会提示重建。退出后清理本轮大块采集暂存与日志，保留复用所需的起始游标；完整重建成功后清理上一份搜索基库。

## 数据位置

用户设置、排除目录与最终搜索索引保存在 `%APPDATA%\com.kite.launcher`。读取组件安装在受保护的程序目录，采集暂存放在 `%ProgramData%\Kite\FileIndex` 的用户隔离会话中。数据仅在本机使用，不上传。
