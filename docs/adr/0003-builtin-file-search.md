# ADR 0003：默认关闭的内置文件搜索与按需元数据服务

状态：已接受，2026-10-23。取代 ADR 0002 的 Everything 后端依赖决策，保留文件模式优先展示与类型筛选规则。

完整 C/D/E 原型验证了共享名字、分块压缩和按需读取的低常驻方案。文件搜索作为 Kite 内置插件提供，默认关闭；插件页保留开关、状态和管理入口，独立的“文件搜索”设置页集中管理索引与排除目录，不进入外部 PluginHost 或 JSON-RPC 协议。点击主界面“文件”时，在结果列表提供启用入口，确认范围与权限后才安装和启动读取组件。

Kite、索引构建和查询保持普通权限；按需 Windows 服务只读取 NTFS 名字、身份和现有 USN。首次显式启用通过 UAC 安装，之后连接已安装组件不反复提权。服务程序与元数据暂存目录受保护，会话按已认证用户隔离；关闭插件、退出或客户端断连取消读取，无会话时服务退出。采用服务是为了避免每次恢复同步都弹 UAC，不让整个启动器和外部插件一起提权。

普通权限侧仅发布完整的索引代际，失败保留已有基库；启动按不可变基库的原始游标补读，日志不再覆盖该游标或卷身份变化时要求重建。没有自动目录遍历或 Everything 回退，避免把不完整、过期或语义不同的结果伪装成正常搜索。

排除文件夹控制当前用户可见的搜索结果，在计数与截断前按当前路径过滤，包含目录自身和子树。底层保留完整名字元数据，使移入、移出及跨范围硬链接正确同步；界面明确排除不等于停止采集该目录。类别沿用现有图片、文档、视频、音频、压缩包、文件夹筛选。

Everything 的 SDK 适配器保留兼容入口，文件模式不再要求安装 Everything。当前完整 Kite 的功能验证、Release 就绪时间和常驻内存见[验证摘要](../FILE-SEARCH-VALIDATION.md)；历史原型报告和原始采样仅在本机归档，不随产品源码提交。
