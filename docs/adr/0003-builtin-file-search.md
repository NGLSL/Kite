# ADR 0003：默认关闭的内置文件搜索与按需元数据服务

状态：已接受，2026-10-23。取代 ADR 0002 的 Everything 后端依赖决策，保留文件模式优先展示与类型筛选规则。

完整 C/D/E 原型验证了共享名字、分块压缩和按需读取的低常驻方案。文件搜索作为 Kite 内置插件提供，默认关闭；插件页保留开关、状态和管理入口，独立的“文件搜索”设置页集中管理索引与排除目录，不进入外部 PluginHost 或 JSON-RPC 协议。点击主界面“文件”时，在结果列表提供启用入口，确认范围与权限后才安装和启动读取组件。

Kite、索引构建和查询保持普通权限；按需 Windows 服务只读取 NTFS 名字、身份和现有 USN。首次显式启用通过 UAC 安装，之后连接已安装组件不反复提权。服务程序与元数据暂存目录受保护，会话按已认证用户隔离；关闭插件、退出或客户端断连取消读取，无会话时服务退出。采用服务是为了避免每次恢复同步都弹 UAC，不让整个启动器和外部插件一起提权。

普通权限侧仅发布完整的索引代际，失败保留已有基库和最后完整提交的变化状态；启动按完整提交的全卷游标补读，日志不再覆盖所需读取位置或卷／日志身份变化时要求重建。没有自动目录遍历或 Everything 回退，避免把不完整、过期或语义不同的结果伪装成正常搜索。

2026-10-23 后续决定：为支持日常大批文件变化，采用可直接查询的 SQLite 变化层；变化对象按身份更新／删除，delta、shadow、目录 prefix 与全卷 applied cursors 在同一事务持久提交。重启从已提交游标续读，未提交轮次重读；原基库保持不可变，受保护的原始 checkpoint 保留为卷与 journal 身份锚点，本轮暂不全量重写基库。待处理状态使用磁盘暂存与有限缓存，feed 分段并按持久消费 ACK 回收旧段，移除 65,536 个对象／64 MiB 变化层和单会话 512 MiB 日志的累计容量硬失败。此选择以磁盘空间和事务写入换取有界内存及可恢复的大批变化处理；磁盘满、写入失败和实际日志连续性丢失仍明确报错并保留最后完整提交状态。

排除文件夹控制当前用户可见的搜索结果，在计数与截断前按当前路径过滤，包含目录自身和子树。底层保留完整名字元数据，使移入、移出及跨范围硬链接正确同步；界面明确排除不等于停止采集该目录。类别沿用现有图片、文档、视频、音频、压缩包、文件夹筛选。

文件搜索统一使用内置索引，移除 Everything SDK、旧 IPC 适配器及其安装/运行状态提示，减少分发与维护面。覆盖安装时清理旧版随包部署的 SDK 资源，用户单独安装的搜索工具保持原状。当前完整 Kite 的功能验证、Release 就绪时间和常驻内存见[验证摘要](../FILE-SEARCH-VALIDATION.md)；历史原型报告和原始采样仅在本机归档，不随产品源码提交。
