# Kite v0.6.6

## 版本重点

文件搜索恢复失败后继续在后台定时重试，无需重新启用或手动点击恢复。等待期间显示原因和倒计时，环境恢复后自动继续同步。

## 后台重试

- 失败后按 30 秒、1 分钟、2 分钟、最长 5 分钟退避重试；文件搜索保持启用期间不限尝试次数。
- 达到就绪后清零计数，后续独立故障重新从 30 秒开始；清除已完成的旧重建意图，普通连接失败优先复用已有索引和持久游标。
- 首次明确的日志断档仍立即自动重建；重建失败后先等待，避免连续全盘扫描。新索引完整就绪后才替换旧索引。
- 等待期间释放当前读取会话，不额外占用卷读取；使用单调时钟计时，关闭、退出或“立即重试”会唤醒等待。
- “立即重试”继续原本未完成的任务。未发布的新索引候选和临时清单及时回收，清理失败时先重试清理，避免长期重试堆积磁盘。
- 授权被拒绝、读取组件需要安装或更新时等待用户明确操作，后台重试不自动安装组件或反复弹出 UAC。

## 升级与验证

- 读取组件协议继续为 4，现有基库和持久变化层格式不变。安装器保留设置与用户数据。
- 本机只执行必要编译、目标格式和差异检查；未新增测试用例。
- 完整 CI、正式构建和安装验收统一由 GitHub Actions 执行。原有大批真实文件变化、日志切段回收及自动重建验收继续保留。
- 在独立 runner 的隔离 profile 上临时独占锁定既有索引清单，实际观察 30 秒和 60 秒后台等待；释放锁后同一 session 必须自动恢复就绪、复用同一代际、清零计数并通过查询，全程不发送手动重试或重建命令。实际结果由下方自动报告提供。

## 验证边界

- 后台重试持续到功能关闭或程序退出。需要用户授权时保留提示和入口。
- 人工桌面交互、全部旧版本迁移、恢复中强制崩溃、磁盘满及长期运行观察未包含在静默安装验收内。
- 安装包未做 Authenticode 数字签名。
