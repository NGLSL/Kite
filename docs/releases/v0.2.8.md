# Kite v0.2.8

## 版本重点

修复设置页「重新扫描」看起来没反应的问题：点击后立刻有进度提示，扫描结束后无论索引是否变化都会给出完成反馈。

## 修复

- 设置页与托盘触发的重新扫描，在点击后立即提示「正在重新扫描应用索引…」，扫描完成后提示「扫描完成，共 N 条」。
- 索引内容未变化时也会通知 UI；此前只有快照真正被替换才会刷新，应用无增删时用户看不到任何结果。
- 快照内容比较补上 Windows 设置标准搜索词（`search_context`），避免系统词汇变化被误判为「无变化」而不发布。

## 升级影响

设置、历史记录、固定项、别名和安装目录无需迁移。从上一版覆盖安装即可。

## 已知限制

安装包仍无 Authenticode 数字签名。提示条仅在设置页可见；从托盘触发时若正停留在搜索页，完成提示会写入设置页 toast，切到设置页或再次打开时可见。跨机全流程仍依赖用户环境复测。
