# Kite v0.2.13

覆盖范围：`v0.2.12`（`47cd85a`）→ 本版（搜索引擎可配置、窗口内网页搜索、经典 AppsFolder 清洗、结果区细滚动条）。

## 版本重点

搜索侧可自定义引擎与快捷键打开网页结果；索引侧去掉打不开/与开始菜单重复的经典 shell 行；结果列表滚动条不再遮挡 Alt+N。

## 新功能

### 搜索引擎与网页搜索

- 设置页独立「搜索引擎」分区：预设芯片一键切换，也可填自定义模板（`%s` 占位）。
- 窗口内对当前关键词用浏览器搜索：默认 `Ctrl+Enter`，可在设置里改快捷键。
- 存储项：`search_engine` / `search_url_template` / `web_search_hotkey`。

### 经典 AppsFolder 清洗

- 经典 shell 项只有解析到**真实磁盘文件**才入索引：
  - `{KnownFolderGUID}\file`（如内存诊断）展开为绝对路径直接启动；
  - parsing 已是 exe 路径则直接使用；
  - 解不出路径的 AUMID / AutoGenerated 壳丢弃，由开始菜单 `.lnk` 兜底。
- 包应用（含 `!`）仍走 ApplicationActivationManager；经典项不再生成 `shell:AppsFolder\{CLSID}\…` 这类易打不开的行。
- shell 项右键可复制 AUMID / target，便于排查。

### 结果区 UI

- 搜索与设置共用更细的滚动条（4px 拇指、无轨道、hover 加深），避免遮住 Alt+N 选中行。

## 修复

- 解不出真实路径的 `Microsoft.Windows.RemoteDesktop` 等不再与开始菜单同名项双行。
- 经典 AppsFolder 启动分流：有 `!` 的包应用走 ActivationManager，其余走 ShellExecute 整路径。

## 升级影响

设置、历史、固定项、别名无需迁移。从 v0.2.12 覆盖安装后建议**重新扫描**一次应用索引，以便清掉旧缓存中的无效 shell 行。新设置项有默认值，未改过设置的用户无感。

## 已知限制

安装包仍无 Authenticode 数字签名。经典项解析依赖本机 Shell/已知文件夹；极少数仅存在于 AppsFolder、无开始菜单且无真实路径的入口会被过滤。
