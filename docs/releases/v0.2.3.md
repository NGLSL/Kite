# Kite v0.2.3

## 版本重点

修复 Windows 10 上安装器启动后反复重启、快捷键冲突导致无法继续使用，以及升级安装时连带结束 Kite 已启动应用的问题。

## 修复

- 启动时检查 Explorer 令牌是否已经是高权限；没有可用的低权限令牌时继续当前实例，不再无限重启。
- 降权子进程带有一次性标记，并把权限判断、版本和子进程 PID 写入启动日志，方便区分实际安装包。
- 升级安装时只结束旧版 Kite 自身，不再通过 `taskkill /T` 递归结束 Kite 已启动的应用。
- 快捷键被占用时保留应用并主动打开热键设置；改键线程继续运行，只有注册成功才保存新键。
- `kite.log` 滚动覆盖，单文件上限 5,000,000 bytes，达到上限后保留最新记录。

## 升级影响

设置、历史记录、快捷键和安装目录保持不变。安装包版本号为 `0.2.3`。
