# Kite v0.2.7

## 版本重点

把搜索从「名字对得上」推到「想得起、找得到」：索引驱动的多路召回让拼音、简拼、英文缩写和系统设置标准词都能稳定命中；Everything 文件搜索在依赖缺失时给出可操作提示，不再静默空白。

## 新功能

- **索引驱动多路召回**：后台全量扫描与原子索引快照，结合 FST / nucleo / 字符位图等通道，提升拼音全拼、首字母、单词前缀、Camel 拆词、英文缩写和有序跳字的召回稳定性。
- **Windows 设置页标准搜索词**：只读取当前系统页面级 SearchResources 白名单词，补充到已有 `ms-settings` 入口；系统词可扩大召回并支持简拼（如「启动任务」→ `qdrw`），但评分明确低于真实名称和可信别名，不会挤掉本意入口。
- **Everything 依赖状态可见**：文件模式下若未安装 Everything，结果顶部提供官方下载页入口；若已安装但未运行，提示先启动 Everything。Kite 仍不会自动拉起 Everything 窗口。
- **应用发现与索引稳定性**：扩展 Windows 应用发现路径，监听入口变更并合并重建；保持 AppItem 在不同来源间身份稳定，减少重复项与结果抖动。
- **可信别名独立拼音证据**：内置/可信关键词的全拼与简拼单独记分，避免 `kj` 这类短简拼被宽松名称拼音误伤。

## 修复

- 安装器升级时避免自我移除导致的覆盖安装失败。
- Shell 图标 COM 初始化，以及 `.lnk` 图标索引与通用图标缓存恢复。
- 单字母拼音首字母与 `Alt+数字` 启动在结果重排后的行为更稳定。
- AppsFolder 分阶段结果去重与图标来源修正；隐藏搜索结果中的技术性 target 细节。
- 文件查询关闭后正确失效，避免陈旧 Everything 结果残留。

## 升级影响

设置、历史记录、固定项、自定义别名、快捷键和安装目录无需迁移。从 v0.2.5 或更早版本升级时，请从本 Release 页下载并运行 `kite-setup.exe`。v0.2.6 的 GitHub Release 工作流未完成发布，本版安装包已包含该版本计划中的 Scoop shims 索引、常用系统工具入口和签名政策说明。

## 已知限制

- 安装包仍无 Authenticode 数字签名，Windows 可能显示未知发布者；请从本仓库 Releases 下载并核对发布页 SHA-256。
- Windows 设置标准词依赖本机 Settings SearchResources；不同语言包或精简系统可能覆盖不全，不影响静态关键词与应用搜索。
- Everything 仍要求本机已安装并运行官方 Everything；Kite 只做 IPC/SDK 查询，不自建文件索引。
- 本机已通过 `cargo test` 与安装包构建；跨机覆盖安装与文件模式全流程仍依赖用户环境复测。
