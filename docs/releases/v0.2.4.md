# Kite v0.2.4

## 版本重点

改进 Windows 上的界面字体选择，减少部分电脑出现搜索结果和设置页文字字形异常的风险，并在日志中记录本次请求的字体族，便于继续排查。

## 修复

- 根据系统已安装且可解析的字体族选择界面字体，不再仅凭预设字体文件名判断是否安装。
- 简体中文界面优先使用已安装的 Noto Sans SC；否则尝试 Windows 消息字体，再尝试微软雅黑 UI、微软雅黑和等线。没有可用候选时使用 Iced 的默认字体回退。
- 搜索结果名称、设置页标题与普通界面文字使用一致的字体族；日志记录请求的字体族、系统消息字体和字体扫描耗时。

## 升级影响

设置、历史记录、快捷键、安装目录和运行资源保持不变。安装包版本号为 `0.2.4`。

## 已知限制

报告字形异常的电脑尚未复测本版本。如果仍有异常，请提供同一界面的截图和本次启动日志中的 `ui font requested=` 记录；该记录表示请求的字体族，不代表最终绘制每个字形所用的字体。
