# Kite v0.2.9

覆盖范围：`v0.2.8`（`a07414c`）→ 本版（含 SourceLayer 分层、冷/暖启动、搜索管线与 last-good 稳定性）。

## 版本重点

空 Query 只展示正式应用；冷启动先出可搜索首屏，再后台补全。搜索改为常驻 worker + 代际取消，输入更跟手。同产品多入口收敛成一行，System32 / 命令发现源不再刷屏。

## 新增

### 启动与索引

- **SourceLayer 分层（Tier A/B/C）**：Formal 白名单（开始菜单/桌面/UWP/apps-folder/用户 Portable）空 Query 可见；Tier B 仅 curated 系统入口；Tier C（App Paths/Uninstall/Scoop/WinGet 等）只作精确命令或兜底。
- **Cold Bootstrap**：首屏扫高价值正式入口并带图标；`BootstrapReady` 独立推进索引代际并立刻刷新，不再误用 Full 的 pending 语义。
- **Warm Start**：兼容 last-good 快照直接恢复；启动后后台 Full 刷新。快照过期仅记日志，不再硬拒。
- **last-good 原子写**：`ReplaceFileW` / `MoveFileExW` 覆盖索引快照，避免「先删再改名」中间态损坏。
- **单实例**：再次启动会激活已有主窗口。

### 搜索

- 常驻 app-search worker：latest-wins、协作式取消；结果组装收拢到 worker 路径。
- 匹配证据（命中位置/字段）贯穿排序；同产品多入口折叠时保留启动身份。
- 降权（Demote）与偏好加分统一；demoted 表 schema 迁移。
- 评分诊断标签（调试用，不改变排序）。
- 短输入与启动组覆盖收紧；SymSpell 删除种子缩小，按键路径减负。

## 修复

- Bootstrap/Fast 不再按本轮 `seen` 裁剪 LNK 缓存，Full 不必整树重解析。
- 空 Query 补满隐藏 System32 噪声（含 Narrator 等），仍可搜索、可 Pin。
- shell+exe、双 `.url` 等同名 Formal 收敛成一行；不同安装根/不同 args 保留两行。
- 文档类 `.lnk`（PDF 说明书等）不进索引。
- 异步启动关闭、alias cache、demote 合并缺口。
- 交互路径日志统一挂在 Query 日志开关后。
- 设置/托盘重扫仍走 `FullIndexReady`，保留完成提示。
- 安装器去掉旧版卸载组件段。

## 升级影响

设置、历史、固定项、别名无需迁移。从上一版覆盖安装即可；首次启动可能多跑一轮后台 Full 以刷新分层索引。

## 已知限制

安装包仍无 Authenticode 数字签名。同名 shell 吸收在极端撞名场景仍可能过合并，实机若出现可用 dry-run 测试对照。跨机全流程仍依赖用户环境复测。
