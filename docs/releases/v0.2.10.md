# Kite v0.2.10

覆盖范围：`v0.2.9`（`319ad29`）→ 本版（稳定性与索引健康可见性；SourceLayer 实机验收收口）。

## 版本重点

不改搜索算法，把 v0.2.9 大改后的稳定性做实：侧缓存与 last-good 同一套原子写，Full 成败与快照年龄在日志和设置页可见，发布流程固定「main 绿再打 tag」。

## 新增

### 索引稳定性

- **统一 JSON 原子写**：索引快照、LNK 解析缓存、UWP 枚举缓存、exe 元数据缓存共用 `ReplaceFileW` / `MoveFileExW` 覆盖路径；写失败写日志（含路径），不再静默。
- **Index Health**：记录最近 Full 成功/失败、连续失败次数、Warm 快照年龄与是否 aged；状态落在数据目录 `index-health.json`。
- **设置页「索引健康」**：应用索引分区只读一行，区分正常 / 快照过旧 / 完整扫描失败。

### 发布流程

- 文档与 Release 校验固定「合并 main → CI 绿 → 再打 tag」；Release 会检查 tag 提交是否已有成功的 `ci.yml` 运行。NSIS 与完整发布仍只在 tag 上执行。

## 修复与验收

- Bootstrap/Fast/LNK/UWP/Meta 缓存写盘与 last-good 对齐，降低进程被杀后静默全量重解析的风险。
- Warm Start 策略不变：schema 兼容即可恢复；aged 只记日志与健康展示，不硬拒。
- SourceLayer Windows 实机三项收口：冷启动图标与无注册表杂讯、App Paths 兜底与 helper 过滤、空列表与 `7` / `7z` 行为（通用分层规则，无产品特判）。

## 升级影响

设置、历史、固定项、别名无需迁移。从 v0.2.9 覆盖安装即可。数据目录会新增 `index-health.json`；可随时删除，不影响搜索。

## 已知限制

安装包仍无 Authenticode 数字签名。扫描过程本身不返回结构化错误；Full 失败目前以 last-good 写入失败为主要观测点。跨机全流程仍依赖用户环境复测。
