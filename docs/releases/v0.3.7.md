# Kite v0.3.7

## 版本重点

这一版以结构整理和可感知的小修复为主：搜索热路径减少重复读库，工具窗与设置更新逻辑拆分更清晰；结果右键不再出现开发向的「复制 target / AUMID」；手动录制全局快捷键时，Alt+Space 会正确录入而不是弹出 Windows 系统菜单。

## 新功能与体验改进

- 代码级性能基线纳入仓库：`cargo test --release report_perf_baseline -- --ignored --nocapture` 可在不唤起 UI 的情况下压测搜索、插件故障、Everything 降级、DPI 与存储升级路径（见 `docs/PERFORMANCE.md`）。
- 搜索个性化（固定、降权、启动历史）改为 UI 侧缓存，按键路径不再每次全量读取 usage；启动/固定/降权等会主动失效缓存。
- 插件 Provider 查询改为常驻 worker（与应用搜索 worker 同构），只处理最新请求，代际过期结果不会覆盖当前列表。

## 修复

- 设置页「按下组合键」录制时，Alt+Space / Ctrl+Alt+Space 等系统冲突组合由热键线程临时 `RegisterHotKey` 接管，录入快捷键而不再唤起窗口系统菜单；Esc 或关闭设置会恢复原全局键。
- 结果右键菜单去掉「复制 target」和「复制 AUMID」；文件类结果仍保留「打开所在文件夹 / 复制路径」，其余为复制名称、固定与优先级。

## 升级影响

- 设置、历史记录、固定项、别名、用户插件与快捷键配置无需迁移。
- 默认全局快捷键仍为 Alt+Space；已在运行实例上改键后的行为与旧版一致。
- 安装包升级路径不变；官方插件资源随安装包同步。

## 验证与限制

- 本地完整 `cargo test`：558 通过、11 忽略、0 失败。
- 本地 `cargo build --release` 通过。
- 工具窗统一、family/merge 契约、检索通道拆分与插件 worker 为行为保持型重构；搜索相关回归测试覆盖合并与纠错通道。
- 热键录制吞键、右键菜单与工具窗交互仍建议在 Windows 实机点检；发布工作流会在 Windows 上重跑测试并生成 NSIS 安装包。
- 安装包仍无 Authenticode 数字签名。
