# Kite v0.2.6

## 版本重点

让 Scoop shims 和常用 Windows 系统工具进入搜索结果，并在仓库及发布页面明确说明当前安装包的签名状态。

## 修复与改进

- 扫描当前用户和全局 Scoop 的 `shims` 目录，优先纳入快速索引，修复只通过 Scoop 安装、没有开始菜单快捷方式的程序搜不到的问题。当前覆盖 `.exe` 和 `.lnk` shim。
- 搜索可直接找到回收站、控制面板、注册表编辑器、任务管理器等常用系统工具；文件型入口只会在目标文件存在时显示。
- 补充 Everything SDK 的 MIT 版权和许可全文，安装器会将第三方声明一并安装。
- README 和 Release 页面增加 Code signing policy 入口，说明 Kite 正准备申请 SignPath.io 开源项目签名，目前尚未获批；本版安装包没有 Authenticode 数字签名。

## 升级影响

设置、历史记录、快捷键和现有安装目录无需迁移。安装时会更新程序文件并安装 `THIRD_PARTY_NOTICES.txt`。

## 已知限制

签名证书仍在后续申请计划中，本版安装包未签名。Windows 可能显示未知发布者提示；请从本仓库的 GitHub Releases 下载，并核对发布页记录的 SHA-256。

Scoop 扫描目前仅覆盖 shim 目录中的 `.exe` 和 `.lnk`；未创建 shim 或开始菜单快捷方式的包不会因此出现在索引中。截图中的两个 `wps.exe` 是否指向同一目标尚未确认，本版不按名称强行合并不同路径的应用。本地自动化测试覆盖了 Scoop 索引和系统工具搜索，本机 `ShellExecuteW` 验证了回收站和控制面板入口返回成功；反馈电脑上的实际点击启动仍需复测。
