# Kite v0.3.4

## 版本重点

本版让文件搜索更容易进入和筛选：搜索栏显示「文件」入口，进入文件模式后可按图片、文档、视频、音频、压缩包或文件夹过滤 Everything 的结果。文件类型下拉框采用与 Kite 主题一致的颜色和圆角，并移除了菜单周围突兀的黑色阴影。

官方插件也改为通过搜索结果进入：选择插件条目后再输入插件查询。新增独立的 SHA-256 文本哈希工具窗口。

## 改进与修复

- 文件搜索支持「全部、图片、文档、视频、音频、压缩包、文件夹」筛选；在取前排结果之前应用类型过滤。
- 搜索栏恢复可见的文件入口，并显示当前文件搜索模式；切换筛选类型后刷新结果。
- 调整文件类型下拉框的尺寸、边框、文字与选中态，使其贴合深色和浅色主题。
- 插件触发项作为可选的搜索结果展示；选中后再进入插件输入，减少与普通应用搜索的干扰。
- 新增 SHA-256 文本哈希工具，支持输入、粘贴、复制和清空；开发工具中的哈希命令改用 SHA-256。

## 升级影响

- 设置、历史记录、固定项和别名无需迁移。
- 文件搜索继续使用本机 Everything；需要安装并运行 Everything，且查询至少包含两个规范化字符。文件类型筛选只作用于文件结果。
- 官方插件随安装包更新；用户安装的第三方插件不受影响。

## 验证

- 本地主项目测试：544 通过、10 项按项目设置忽略；官方插件测试：14 通过。
- 本地 release 构建通过。
- Windows CI 会在合入 main 后重新执行测试和 release 构建；发布工作流会生成 NSIS 安装包并附带构建报告和 SHA-256。

## 已知限制

- 安装包仍无 Authenticode 数字签名。
- 文件类型依据 Everything 返回的路径和扩展名分类；未归入上述类型的文件可在「全部」中搜索。
