# Kite v0.2.11

覆盖范围：`v0.2.10`（`5cf4490`）→ 本版（右键菜单与托盘设置窗口交互修复）。

## 版本重点

两处窗口交互回归：列表右键菜单二次点击应关闭；托盘菜单「设置」应可靠弹出设置页。

## 修复

### 列表右键菜单

- **第二次右键关闭弹窗**：菜单已打开时再右键结果行会关闭菜单，而不是立刻重新打开。
- 根因：右键会先走全局 `MousePressed`（点在菜单外则关闭），再走行上的 `ContextMenu`（总是打开）；两者叠加导致关不掉。
- 现行为：`ContextMenu` 做开关切换；左键点菜单外仍关闭；右键不再抢跑关闭。

### 托盘「设置」

- **托盘菜单点击「设置」能弹出设置窗口**。
- 根因：`Task::batch` 并行执行时，`gain_focus` 可能早于 `set_mode(Windowed)`。窗口不可见时 `gain_focus` 是 no-op，再叠加 `skip_taskbar`，设置页容易被压在其它窗口后，看起来像没弹出来。
- 现行为：先显示/调整窗口，再聚焦；并按光标所在显示器定位 720×520 设置页。托盘打开主窗口路径同样改为先显示再聚焦。

## 升级影响

设置、历史、固定项、别名、快捷键均无迁移。从 v0.2.10 覆盖安装即可。

## 已知限制

安装包仍无 Authenticode 数字签名。右键菜单与托盘为 Windows 实机交互，单元测试覆盖状态切换逻辑，完整点选仍建议本机复测。
