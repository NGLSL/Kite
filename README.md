# Kite

Minimal Tauri 2 + React + TypeScript desktop launcher skeleton.

```powershell
npm install
npm run tauri dev
npm run tauri build
```

Rust toolchain on this machine: `RUSTUP_HOME=D:\Tools\rustup`, `CARGO_HOME=D:\Tools\cargo`, target `x86_64-pc-windows-msvc`.
MSVC Build Tools: `D:\Tools\VS2022BuildTools`.
