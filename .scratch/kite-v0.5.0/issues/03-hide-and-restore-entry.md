# 03：隐藏应用入口并在设置中恢复

Status: done
Category: enhancement
Blocked by: 01 结果操作面板与键盘入口

## What to build

用户选择“隐藏此入口”后，该稳定启动身份立即从搜索建议、最近区和固定区消失；用户可在设置中查看名称、目标和参数摘要并恢复，重扫和重启保留选择。

## Ownership and contracts

- 负责隐藏记录存储与迁移、偏好快照、非空与空 Query 可见性过滤、面板动作、设置恢复入口及相应回归。
- 隐藏独立于 Demote，以规范化目标与参数形成的稳定身份为单位。同身份重复来源全部隐藏，不扩大到整个安装族或其他启动身份。
- 过滤在归并与 Top N 截断前完成；空 Query 使用其实际构建入口处理，不能只在渲染时过滤。
- Alias、Pin 和历史不绕过隐藏，但原始记录保留；明确路径访问及文件、网页、系统和插件结果不受此应用隐藏模型控制。
- 统一身份迁移以事务覆盖隐藏及既有相关用户状态，补齐当前未纳入迁移的 Demote；不把偏好转移给同名不同目标。

## Acceptance criteria

- [x] 隐藏后普通查询、Name Exact、Alias、最近区和固定区均不再显示该启动身份。
- [x] 可见候选足够时补足结果名额；未隐藏项的明确匹配保护和现有排序保持。
- [x] 冷缓存、热缓存和在途旧搜索均遵守最新隐藏选择，旧任务不能让隐藏项再次出现。
- [x] 同身份的重复来源一起隐藏；同归并组中其他身份仍可显示，不继承隐藏身份的用户偏好证据。
- [x] 设置中可查看并恢复；目标暂时不在索引中时仍可管理隐藏记录。
- [x] 恢复后 Alias、Pin、Usage、Query History 和 Demote 继续适用，重启与重扫仍然正确。
- [x] Alias 目标候选不展示隐藏项；已有 Alias 保留且可识别其目标被隐藏。
- [x] 旧库升级和身份迁移保留所有相关数据；模拟写入或迁移失败时不产生部分成功与虚假提示。

## Validation

- 复用统一搜索、空 Query 列表、存储重载、身份迁移和 UI 消息入口测试；新增必要隐藏/恢复回归。
- 在足够候选的 fixture 中验证 Top N 补位，并验证同组不同身份及同名不同目标。
- 运行受影响的存储、搜索和 UI 测试及 `cargo check`；记录固定评估中未隐藏样本的结果。
- Windows 开发构建：隐藏精确命中和固定项、恢复、重扫、重启，并核对明确路径仍可打开。
