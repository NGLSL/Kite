# 06：添加快捷方式并从路径结果快速登记

Status: done
Category: enhancement
Blocked by: 05 添加和管理单个手动 exe 应用

## What to build

用户能够登记可解析的 `.lnk` 并保留其静态参数、工作目录和图标来源；搜索一个有效 exe 或 lnk 的绝对路径时，可直接选择“添加到 Kite”，复用登记确认表单。

## Ownership and contracts

- 负责快捷方式登记验证、既有解析器接入、路径结果适用动作、登记表单预填及相关归并/启动/UI 回归。
- 复用 05 的登记、稳定身份、管理与快照流程；不增加另一种持久化身份或独立启动器。
- 只使用现有解析器能验证并形成可启动目标的快捷方式。首版不开放参数、工作目录或终端编辑。
- 路径动作只对可登记的 exe/lnk 提供；普通文件、目录、URL、设备路径和不存在路径不出现该选项。
- 快捷方式外部改动在既有重扫时重新解析；目标或语义参数变化视为新身份，不迁移旧偏好。

## Acceptance criteria

- [x] 设置中登记真实 lnk 后，实际启动保留原解析参数与工作目录，图标失败不影响登记。
- [x] 损坏、无法解析或无法形成已验证启动目标的 lnk 明确拒绝，不保存半成品。
- [x] 有效 exe/lnk 路径结果可预填同一个登记表单，确认后进入正常搜索；取消不写入数据。
- [x] 普通文件、目录、URL 和无效路径不出现“添加到 Kite”。
- [x] 同 target 与等价 args 的手动、快捷方式和自动入口归并；同名不同 target、不同语义参数保持独立。
- [x] 外部修改快捷方式目标后重扫，不把旧 Alias、Pin、历史或隐藏状态赋给新身份。
- [x] 移除登记保留原快捷方式文件；重启后有效登记、名称和导入元数据保持。
- [x] 中文、空格及合法特殊字符路径正确处理，不把路径文本作为任意 shell 命令执行。

## Validation

- 使用真实 Windows 快捷方式 fixture 验证登记到索引及启动元数据，补必要失败和身份归并回归。
- 复用路径直达和 UI 消息测试，验证适用动作、预填、确认及取消。
- 运行受影响的扫描、路径、存储与 UI 回归及 `cargo check`。
- Windows 开发构建启动带参数和工作目录的测试快捷方式，核对实际进程行为，不能仅检查解析字段。
