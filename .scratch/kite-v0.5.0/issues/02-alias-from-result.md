# 02：直接给当前结果设置 Alias

Status: done
Category: enhancement
Blocked by: 01 结果操作面板与键盘入口

## What to build

用户从应用结果的操作面板直接设置 Alias，无需进入设置或再次查找目标。保存后立即能用该 Alias 搜到原应用，重启后继续有效。

## Ownership and contracts

- 负责主搜索 Alias 编辑交互、既有 Alias 持久化调用、搜索缓存失效和相关行为测试。
- Alias 绑定已经确认的 AppItem 稳定身份，沿用现有规范化规则；不能只依赖自由输入的目标名称。
- 非空 Query 可作为可编辑建议。空 Alias 不保存；相同映射幂等，不同目标的冲突必须显式选择是否替换。
- 只为适用的索引应用提供此动作，不新增文件、内置项或插件 Alias 类型。

## Acceptance criteria

- [x] 选中应用 → 操作面板 → 设置 Alias → 保存 → 搜索 Alias，最终目标与原选中身份一致。
- [x] 保存成功后立即刷新当前搜索；基础候选缓存与在途旧任务不能重新引入旧 Alias 映射。
- [x] 同名 Alias 指向不同应用时展示原目标和新目标；取消保留原映射，确认才替换。
- [x] IME 组合态不误保存；Esc 先取消编辑，再按原面板层次返回，Query 保留。
- [x] 保存失败保留编辑输入并显示错误；目标已失效时不绑定其他应用。
- [x] 重启后 Alias 仍指向相同身份；既有设置页的 Alias 添加与移除保持有效。

## Validation

- 复用 UI 消息更新、Alias 存储重载和既有缓存失效测试，断言最终目标及冲突取消后的数据。
- 补充必要搜索回归，运行相关 Alias/UI/搜索检查和 `cargo check`。
- Windows 开发构建演示完整设置、取消、冲突替换、重新搜索及重启链路。
