# 05：添加和管理单个手动 exe 应用

Status: done
Category: enhancement
Blocked by: 03 隐藏应用入口并在设置中恢复

## What to build

用户在设置粘贴一个有效 `.exe` 绝对路径并确认显示名称后，能搜到、固定、设置 Alias、隐藏和启动该应用。登记可改名和移除，重扫和重启后保留，与自动扫描结果不重复。

## Ownership and contracts

- 负责手动应用持久化与迁移、路径验证、原始扫描候选输入、归并/快照构建、设置列表和相关回归。
- 持久化登记是事实来源，不能依赖扫描缓存；快速与完整构建均包含有效手动项。
- 手动项沿用规范化 target 与 args 的稳定启动身份，与自动项一起进入现有去重和发现项归并；手动登记为正式来源，不追加到最终列表绕过归并。
- 同身份优先保留用户名称和已验证的手动启动元数据；自动名称继续可搜索。登记记录 ID 不用作搜索或偏好 ID。
- 移除登记只移除其记录和自定义名称，不删除文件；独立存在的自动入口与偏好继续保留。
- 依赖 03，以便在一套已完成迁移的隐藏/偏好契约上验证手动与自动入口切换。

## Acceptance criteria

- [x] 添加有效 exe 后当前索引更新，普通名称、中文/拼音、Alias、Pin、历史和隐藏均可使用。
- [x] 首次登记拒绝不存在或不符合绝对路径规则的目标；不将 Query 拼成命令或参数。
- [x] 重复登记及同身份自动入口只显示一次，用户名称和原自动名称均可搜索。
- [x] 改名不改变启动身份和偏好；删除登记后仍存在的自动入口保留原有用户状态。
- [x] 重扫、重启和快速到完整快照切换不丢失登记，不短暂恢复已隐藏身份。
- [x] 已登记目标消失时管理列表保留并标记不可用，不生成可启动建议；目标恢复并重扫后重新可用。
- [x] 存储失败不保留虚假登记，不显示成功；旧库升级保持已有设置、历史与插件配置。
- [x] 显示图标失败不阻止有效登记和搜索；已有 CLI 默认工作目录与终端行为保持。

## Validation

- 临时目录中登记实际有效 exe，走持久化 → 快速/完整索引 → 查询结果的行为链，关闭重开存储验证保留。
- 复用稳定身份与归并测试，覆盖自动同身份、同名不同目标、改名、删除登记、隐藏及偏好保留。
- 运行受影响的存储、扫描、搜索和 UI 回归及 `cargo check`。
- Windows 开发构建实际启动登记程序，验证中文/空格路径、重启、文件暂时移开后恢复。
