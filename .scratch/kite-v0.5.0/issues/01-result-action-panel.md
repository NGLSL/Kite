# 01：结果操作面板与键盘入口

Status: done
Category: enhancement
Blocked by: None (can start immediately)

## What to build

用户在主搜索窗口选中结果后，用 Shift+F10 或右键打开同一个紧凑操作面板，通过上下键、Enter 和 Esc 执行或取消已有操作。后台结果重排不能改变已打开面板的目标。

## Ownership and contracts

- 负责主搜索 UI、键盘事件路由、上下文动作和相关 UI 消息测试；不引入新的数据库结构。
- 统一键盘和鼠标的适用动作与执行逻辑，保留已有目录定位、复制、Pin 和 Demote。
- 捕获打开时的结果身份和 Query；修改或启动前按当前索引确认目标，不能依赖可变结果下标。
- 设置页、工具窗和热键录制态不触发面板；面板开启时不让主搜索重复处理 Enter、Alt+数字和导航事件。
- 本任务为后续 Alias、隐藏及查询纠正提供动作入口，不提前实现这些功能。

## Acceptance criteria

- [x] Shift+F10 与右键可打开同一适用动作列表，文件、应用、内置项和插件结果不出现无效操作。
- [x] 面板内上下键选择、Enter 执行、Esc 关闭；关闭后保留 Query 并恢复输入或原结果导航。
- [x] 复制、目录定位、Pin 和 Demote 等原有动作仍按既有契约工作。
- [x] 打开后结果重排仍操作原目标；目标失效时明确拒绝，不操作后来占据该下标的结果。
- [x] IME 组合态 Enter 不触发动作；面板外原有快捷键和编辑行为正常。
- [x] 操作失败显示原因；保存类动作不得在存储失败时显示成功。

## Validation

- 复用共享 UI 测试状态和消息更新入口，覆盖键盘/右键一致性、重排、过期目标、IME 与 Esc。
- 运行相关 UI 回归及 `cargo check`；完成此任务的适当自动检查后记录结果，不机械重复无关性能测试。
- Windows 开发构建冒烟：呼出面板、复制、目录定位、Pin/Demote、取消及中文组合输入。
