# 03: Search Two-Column Cards

**What to build:** 当用户在搜索框中敲入文字进行搜索时，主界面从网格模式平滑过渡为横向双列（2-Column）卡片搜索流。640px~720px 的窗口宽度被充分对称利用，彻底告别单列细长条导致的横向大片死白/死黑留白。左列项目对应快捷键 `Alt+1` ~ `Alt+4`，右列项目对应快捷键 `Alt+5` ~ `Alt+8`。每张卡片展示清晰大图标、应用/功能全名、智能缩略路径及实体微立体质感键帽徽标。选中态采用现代圆角柔光微高亮，移除机械的 3px 竖条。

**Blocked by:** 02: zTools Grid Dashboard

**Status:** resolved

- [x] 在 `search_view.rs` 中重构非空 Query 时的结果列表渲染，排布为左右对称的横向双列卡片布局。
- [x] 左列绑定 `Alt 1~4`，右列绑定 `Alt 5~8`，用户可直接通过 `Alt+N` 或方向键加回车启动对应卡片。
- [x] 卡片内部合理编排 36px 图标、15px 加粗标题、11px 路径/副描述，并带微型分类徽标（如 `应用`、`文件`）。
- [x] 选中项采用半透明圆角柔光与 1px 微光边框高亮，彻底干掉左侧 3px 纯蓝粗竖条。
- [x] 调整滚动条与双列卡片的边距，为右侧键帽保留 16px 以上的安全呼吸间隙，杜绝遮挡贴边。
- [x] 搜索结果清空（按 Backspace 删空）时即时且无卡顿地切回网格仪表盘。
