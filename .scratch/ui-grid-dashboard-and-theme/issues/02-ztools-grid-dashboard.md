# 02: zTools Grid Dashboard

**What to build:** 在用户刚唤醒启动器且搜索框为空（空 Query）时，将原有的单列垂直列表重构为高密度的 zTools 风格横向图标网格仪表盘。包含两排“最近使用”（展示高频启动的 App 与官方插件如计算器、时间戳、JSON 格式化、文件搜索等共 16 项）及一排“已固定”项。彻底移除应用图标外围生硬的灰色圆角方块（`ICON_BG`），让微信、QQ、WeGame、VSCode 等原生图标以 36×36 透明高清直出，消除“框中框”。鼠标单击任意图标即可启动，键盘支持方向键漫游选择，回车启动。

**Blocked by:** 01: Theme Tokens and Skin Switcher

**Status:** resolved

- [x] 在 `search_view.rs` 中重构空 Query 时的渲染分支，渲染高密度横向图标矩阵（Grid Dashboard）。
- [x] 磁贴展示两排“最近使用”（8列 × 2排 = 16项）以及一排“已固定”，包含应用和官方插件，带小字标题。
- [x] 彻底移除应用图标外层的灰色圆角底框，图标采用线性滤波双线性插值渲染，清晰透明无毛边。
- [x] 官方插件设计专属的精致纯色或微渐变微型图标，在网格中清晰直观。
- [x] 支持鼠标 Hover 柔光反馈、单击启动，以及键盘方向键选中后回车启动。
- [x] 在深色（#0F1115）与浅色（#FFFFFF）皮肤下自适应着色，无三段式割裂横线。
